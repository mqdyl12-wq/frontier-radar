# PaperLens · 学术论文双语精读工作台

访问路径：`/frontier-radar/reader/`（独立于前沿雷达主页）。

## 使用方法

1. 在阅读器中上传英文 PDF：仅用浏览器 PDF 预览，不上传到 GitHub。
2. 点击“复制 ChatGPT 精读指令”，打开 ChatGPT 网页端，上传相同 PDF 并粘贴指令。
3. ChatGPT 按论文物理页逐段翻译、标注每段作用、解释理论与方法，生成可下载的 JSON。
4. 在 PaperLens 页面导入 JSON，即可在右侧逐段查看。长论文支持多批文件按段落编号合并。
5. 可搜索、中英对照、仅看重点、跳转 PDF 页、标注段落及保存研究笔记。
6. 定期点击左侧“导出当前解读与笔记”进行备份。

## 关于 GPT 网页版

ChatGPT 网页版不能直接嵌入第三方静态网站作为免费推理后端，因此**仅上传 PDF 不会自动生成翻译**。需要先由 ChatGPT 处理 PDF，再将结构化结果导入网页；不使用额外的付费模型 API。

## 隐私与学术规范

- 网站源代码为公开静态网页，但用户 PDF 文件、译注及笔记不会上传到 GitHub。
- 解读内容与笔记保存在浏览器本地存储；跨设备使用时须自行导出和导入，浏览器清理数据可能使其丢失。
- PDF 仍需单独重新选择，JSON 备份不包含 PDF 文件。
- 多栏、扫描文字、图表和公式可能被 ChatGPT 误读；译文、页码及统计结果须核对原文。
- 首页内置的5个段落**为明确标识的虚构演示**，不能引用为真实研究证据。

本页面无需安装前端框架，HTML 单文件即可运行。
## v2：论文论证结构与 PDF 精准定位

打开论文 PDF 后，浏览器会按需从 Mozilla PDF.js 的固定版本 CDN 加载公开 JavaScript 库，在**本机**渲染 PDF 和提取文本。右侧段落的“定位原文”将先跳到**PDF 物理页码**，再尝试匹配本段 `original` 的前部文字并高亮对应行。只在找到足够长的文本锚点时显示高置信度提示；短匹配、重复匹配会标注“局部匹配”，找不到就退回翻页，不伪造位置。

- 有网络才能加载 CDN；CDN 受限或扫描版 PDF 无可提取文本时，仍可使用浏览器原生 PDF 浏览和页码跳转。
- PDF.js 定位只高亮与**原文开头**相符的行，不保证整段全部高亮；对双栏、跨页、字体编码以及公式图表请人工核对。用户的 PDF 字节在本机处理，不上传到 GitHub Pages。
- 新增“论证结构图”：由已导入的章节和段落 `role` 生成章节路线与五阶段证据链。没有导入的章节显示“尚未覆盖”，不是论文不存在该部分。点击结构节点返回译注并尝试定位原文。
- 缩放按钮用于按需查看 PDF 细节。

## v2：多篇论文的 ChatGPT 批量初读（无需另付模型 API 费用）

点击 **复制多篇批量初读指令**，在 ChatGPT 一个对话中选择 2–3 篇 PDF 一起上传，并粘贴指令。每篇应生成独立的 UTF-8 JSON，或生成 `{"packs":[...各篇独立 JSON 对象...]}` 的批量文件。重点是**选择性精读**每篇 6–12 个真正重要的自然段，先建立参考框架，不声称完成全文。

回到 PaperLens 点击 **批量导入 JSON**，可一次选择多个 JSON 文件；使用不同 `paper.id` 分别保存阅读记录，同一篇后续批次按 `paragraph.id` 合并。切换论文后，左侧 PDF **不会自动替换**，应重新选择对应原文，避免错配。ChatGPT 如果输出 ZIP，请先在设备上解压后全选 JSON；目前页面不直接解压 ZIP。

适合的工作顺序：
1. 一次上传 2–3 篇候选论文，批量生成核心问题、理论/方法/结果梳理及有依据的选择性译注；
2. 把多份 JSON 一次导入、按论文切换查看，选出关键论文；
3. 用原有“复制 ChatGPT 精读指令”对选定论文按物理页 1–8、9–16 等分批完成全文逐段精读；
4. 对照 PDF 自动定位结果核查重要理论术语、数字、引用和图表。定期导出完整的阅读备份。

**说明**：多份 PDF 上传和多文件生成是 ChatGPT 网页端的能力，不等于能让静态网页在无人操作时调用 ChatGPT。一次完成多篇全文逐段翻译通常会增加漏段/截断风险，因此默认优先小批量选择性精读。文件上传仍受 ChatGPT 使用限制。
