# PaperLens · 学术论文双语精读工作台

访问路径：`/frontier-radar/reader/`（独立于前沿雷达主页）。

## 使用方法

1. 在阅读器中上传英文 PDF：仅用浏览器 PDF 预览，不上传到 GitHub。
2. 点击“复制 ChatGPT 精读指令”，打开 ChatGPT 网页端，上传相同 PDF 并粘贴指令。
3. ChatGPT 按论文物理页逐段翻译、标注每段作用、解释理论与方法，生成可下载的 JSON。
4. 在 PaperLens 页面导入 JSON，即可在右侧逐段查看。长论文支持多批文件按段落编号合并。
5. 可搜索、中英对照、仅看重点、跳转 PDF 页、标注段落及保存研究笔记。
6. 定期点击左侧“导出当前解读与笔记”进行备份。

## 关于 GPT 网页版

ChatGPT 网页版不能直接嵌入第三方静态网站作为免费推理后端，因此**仅上传 PDF 不会自动生成翻译**。需要先由 ChatGPT 处理 PDF，再将结构化结果导入网页；不使用额外的付费模型 API。

## 隐私与学术规范

- 网站源代码为公开静态网页，但用户 PDF 文件、译注及笔记不会上传到 GitHub。
- 解读内容与笔记保存在浏览器本地存储；跨设备使用时须自行导出和导入，浏览器清理数据可能使其丢失。
- PDF 仍需单独重新选择，JSON 备份不包含 PDF 文件。
- 多栏、扫描文字、图表和公式可能被 ChatGPT 误读；译文、页码及统计结果须核对原文。
- 首页内置的5个段落**为明确标识的虚构演示**，不能引用为真实研究证据。

本页面无需安装前端框架，HTML 单文件即可运行。
